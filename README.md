# Уголёк (Ugolek) 🔥

iOS-приложение, которое продлевает «огоньки» (стрики) в TikTok: отправляет твоим друзьям короткое сообщение раз в день — стрик не гаснет.

> Статус: проект в самом начале разработки. Следи за тегами `m0`…`v1.0` в истории коммитов.

## Ключевые факты

- **Платформа:** iOS 17+, только iPhone.
- **Распространение:** sideload через AltStore/SideStore (полная версия не предназначена для App Store).
- **Приватность:** все данные (сессия TikTok, список друзей, история) хранятся только на устройстве, в Keychain и локальных файлах. Ни аналитики, ни серверов.
- **Сборка:** GitHub Actions на macOS-раннере — локальный Mac не требуется.

## Как это работает

Стрик в TikTok живёт, пока другу каждый день уходит хотя бы одно сообщение. Уголёк один раз логинится в твой TikTok (через встроенный браузер), а дальше по расписанию сам открывает веб-инбокс TikTok в скрытом браузере внутри приложения, находит чат каждого друга и отправляет сообщение. Подробности — в `INSTALL.md` (появится позже).

## Отзывы и происхождение

Идея навеяна открытым проектом [TiktokStreakSaver](https://github.com/Jon2G/TiktokStreakSaver) (MIT). Весь код этого приложения написан с нуля и не содержит строк из него.

## Дисклеймер

Автоматизация нарушает пользовательские правила TikTok. Используй на свой страх и риск: приложение отправляет максимум одно сообщение в день каждому другу и делает человеческие паузы, но риск ограничений аккаунта всегда остаётся на тебе.
