# Уголёк (Ugolek) 🔥

iOS-приложение, которое автоматически продлевает «огоньки» (стрики) в TikTok: каждый день отправляет твоим друзьям короткое сообщение — стрик не гаснет.

> **Статус:** v1.1 — фоновые режимы, верификация получателя, авто-определение имени.

## Ключевые факты

- **Платформа:** iOS 17+, только iPhone.
- **Распространение:** sideload через AltStore/SideStore или Sideloadly (полная версия не предназначена для App Store).
- **Приватность:** все данные (сессия TikTok, список друзей, история) хранятся только на устройстве — в Keychain и локальных файлах. Ни аналитики, ни серверов, ни трекеров.
- **Зависимости:** ноль. Чистый Swift/SwiftUI + WebKit.
- **Сборка:** GitHub Actions на macOS-раннере — локальный Mac не требуется.

## Как это работает

Стрик в TikTok живёт, пока другу каждый день уходит хотя бы одно сообщение. Уголёк:

1. **Один раз логинится** в твой TikTok через встроенный браузер (WKWebView). Куки сессии сохраняются в Keychain.
2. **Определяет имя друга** из публичного профиля TikTok (@username) — вводи только логин, имя подтягивается автоматически.
3. **Находит нужный чат**, открывает и **проверяет юзернейм** в шапке открытого чата — гарантированно не напишет не тому (защита от одинаковых имён).
4. **Сверяет, не продлён ли стрик**: если в треде сегодня были сообщения обеих сторон (или только твоё) — пропускает, не шлёт дубли.
5. Вводит сообщение и отправляет. Подтверждает по пузырям и записывает в историю.

### Защита аккаунта

- **Верификация получателя:** перед отправкой Уголёк открывает чат и сверяет @юзернейм в шапке — исключает промахи между друзьями с одинаковыми ники.
- **Авто-определение имени:** при вводе @username приложение подтягивает актуальное имя из публичного профиля TikTok (3-слойный каскад: прямой запрос → браузерный фетч → полный WebView-движок).
- **Дрожание времени:** напоминание ±15 минут от заданного.
- **Пул фраз:** ~30 случайных фраз, разная каждому другу, без повторов подряд.
- **Человеческие паузы:** между друзьями — случайные 2–6 секунд (быстрый режим: 0.8–1.6 с).

## Режимы работы

### Классический (по нажатию)

Тапни «Продлить» на главной, дождись уведомления. Можно сразу свернуть — прогон завершится в фоне благодаря гео-держателю.

### Команды (Shortcuts)

1. Команды → Автоматизации → «+» → «Время суток».
2. Действие: **«Продлить огоньки (фон)»** — не открывает приложение.
3. Отключи «Спрашивать до запуска».

В выбранное время iPhone запустит рассылку без твоего участия (нужна первая разблокировка после ребута).

### Фоновый режим («Гео всегда»)

Настройки → «Гео всегда (авто-продление)» → включить.

- Приложение держит геолокацию минимальной точности (вышки, не GPS) — процесс не замораживается.
- В выбранное время прогон запускается сам, извещение об итоге приходит уведомлением.
- При первом включении — тестовый прогон **без отправки сообщений** для проверки логина и списка друзей.
- Расход батареи: единицы процентов в сутки (синяя стрелка видна).

### Пункт управления (iOS 18+)

Настройки → Пункт управления → «Продлить огоньки». Тап запускает прогон (может мелькнуть приложение; при включённом «Гео всегда» — полностью невидим).

## Дополнительные возможности

- **Ручной скип «Продлили»**: свайп по другу в списке → «🔥 Продлили» (прогон пропустит до конца дня) / «↺ Вернуть в очередь».
- **Автобновление имени**: при отправке «друг не найден» — приложение запрашивает профиль TikTok, обновляет сохранённое имя и повторяет попытку.
- **Импорт/экспорт JSON**: список друзей можно перенести между устройствами.
- **Тёмная тема**, иконка, экран запуска, страница приватности.
- **Локализация RU/EN**, статистика и история прогонов.
- **Суточный негативный кэш**: «страничка не найдена» — приложение не дёргает TikTok повторно до следующего дня.

## Установка

### Через Sideloadly (Windows/macOS)

1. Скачай `Ugolek-unsigned.ipa` из [релизов](https://github.com/Noli4ekc/ugolek/releases/download/rolling/Ugolek-unsigned.ipa).
2. Установи [Sideloadly](https://sideloadly.io/) и iTunes (если Windows).
3. Подключи iPhone по USB, открой Sideloadly, перетащи IPA.
4. Введи Apple ID — приложение подпишется и установится.
5. На iPhone: Настройки → Основные → VPN и управление устройством → доверяй своему Apple ID.

> ⚠️ **Обновление с версии без фоновых режимов:** в новой сборке изменился bundle ID (`com.ugolek.app`). При установке поверх старой iOS considers это новым приложением. **Сначала удали старый Уголёк**, экспортировав список друзей (Друзья → «+» → «Экспорт в JSON»). Куки TikTok в Keychain потеряются — войди заново.

### Через AltStore/SideStore

1. Установи [AltStore](https://altstore.io/) или [SideStore](https://sidestore.io/).
2. Добавь источник Уголька (см. `source.json` в релизах).
3. Установи Уголёк из AltStore.

## Частые вопросы

**Работает ли в фоне?**
Уровень 1 (после тапа 🔥) — да, гео-держатель завершит начатый прогон даже при заблокированном экране. Уровень 2 (Команды) — да, при условии, что приложение запускалось после ребута. Уровень 3 («Гео всегда») — да, полностью в фоне, но тратит немного батареи и показывает стрелку геопозиции.

**Почему десктопный TikTok?**
Мобильная веб-версия TikTok устроена иначе: чат открывается отдельным «экраном», DOM-селекторы другие. Десктопная вёрстка (1920×1080) надёжнее для автоматизации — список и чат видны одновременно.

**Почему огонёк отмечается вручную?**
Веб-версия TikTok не отображает огоньки (стрики) вообще. Поэтому флажок «Есть огонёк 🔥» у каждого друга — ручной.

**Почему для имени нужен THREE слоя?**
Прямой запрос с iPhone блокируется анти-ботом TikTok (отдаёт заглушку в 1,5 КБ вместо профиля). Поэтому работает каскад: URLSession → лёгкий WebView → залогиненный WebView (тот же движок, на котором работает вся рассылка — для TikTok неотличим от реального браузера).

## Сборка из исходников

```bash
# Требуется: macOS с Xcode 16.4+, xcodegen
brew install xcodegen
xcodegen generate
xcodebuild -project Ugolek.xcodeproj -scheme Ugolek \
  -destination 'generic/platform=iOS Simulator' \
  -configuration Debug build
```

CI (GitHub Actions) собирает автоматически при каждом пуше в main.
