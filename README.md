# Уголёк (Ugolek) 🔥

iOS-приложение, которое автоматически продлевает «огоньки» (стрики) в TikTok: каждый день отправляет твоим друзьям короткое сообщение — стрик не гаснет.

> **Статус:** v1.0 — рабочая версия, проверенная на реальном устройстве.

## Ключевые факты

- **Платформа:** iOS 17+, только iPhone.
- **Распространение:** sideload через AltStore/SideStore или Sideloadly (полная версия не предназначена для App Store).
- **Приватность:** все данные (сессия TikTok, список друзей, история) хранятся только на устройстве — в Keychain и локальных файлах. Ни аналитики, ни серверов, ни трекеров.
- **Зависимости:** ноль. Чистый Swift/SwiftUI + WebKit.
- **Сборка:** GitHub Actions на macOS-раннере — локальный Mac не требуется.

## Как это работает

Стрик в TikTok живёт, пока другу каждый день уходит хотя бы одно сообщение. Уголёк:

1. **Один раз логинится** в твой TikTok через встроенный браузер (WKWebView). Куки сессии сохраняются в Keychain — повторный вход не нужен.
2. **По расписанию** (или по тапу на «Продлить сейчас») открывает веб-инбокс `tiktok.com/messages` в скрытом браузере внутри приложения (1920×1080, десктопный Safari UA).
3. **Находит чат каждого друга** в списке, открывает его, вводит сообщение и нажимает отправку.
4. **Подтверждает** отправку по пузырям сообщений и записывает результат в историю.

### Защита аккаунта

- **Дрожание времени:** напоминание приходит в случайное время ±15 минут от заданного — не в одну и ту же минуту каждый день.
- **Пул фраз:** вместо одного сообщения — ~30 случайных фраз, разная каждому другу, без повторов подряд.
- **Человеческие паузы:** между друзьями — случайные паузы 2–6 секунд (быстрый режим: 0.8–1.6 с).
- **Быстрый режим ВЫКЛ по умолчанию** — осторожнее с TikTok.

## Установка

### Через Sideloadly (Windows/macOS)

1. Скачай `Ugolek-unsigned.ipa` из [релизов](https://github.com/Noli4ekc/ugolek/releases).
2. Установи [Sideloadly](https://sideloadly.io/) и iTunes (если Windows).
3. Подключи iPhone по USB, открой Sideloadly, перетащи IPA.
4. Введи Apple ID — приложение подпишется и установится.
5. На iPhone: Настройки → Основные → VPN и управление устройством → доверяй своему Apple ID.

### Через AltStore/SideStore

1. Установи [AltStore](https://altstore.io/) или [SideStore](https://sidestore.io/).
2. Добавь источник Уголька (см. `source.json` в релизах).
3. Установи Уголёк из AltStore.

## Использование

1. **Войди в TikTok:** открой приложение → «Войти» → логинься в TikTok через встроенный браузер.
2. **Добавь друзей:** вкладка «Друзья» → «+» → введи username (без @) или название группы. Отметь флажок «Есть огонёк 🔥».
3. **Настрой расписание:** «Настройки» → «Время напоминания» → выбери время.
4. **Продляй:** тапни «Продлить сейчас» на главной, или дождись уведомления, или добавь кнопку в Пункт управления (iOS 18+).

### Control Center (iOS 18+)

Настройки → Пункт управления → добавь «Продлить огоньки» от Уголька. Теперь можно продлевать стрики прямо из шторки, не открывая приложение.

### Автоматизация через Команды (Shortcuts)

1. Открой «Команды» → Автоматизации → «+».
2. Триггер: «Время суток» — выбери удобное время.
3. Действие: «Продлить огоньки» (приложение Уголёк).
4. Отключи «Спрашивать до запуска» → «Готово».

В выбранное время iPhone сам откроет Уголёк и прогонит отправку — если телефон разблокирован.

## Технические детали

- **XcodeGen** (`project.yml`) — генерация Xcode-проекта, ноль storyboard-ов.
- **WKWebView** (1920×1080, Safari UA) — скрытое окно для автоматизации TikTok.
- **JavaScript-инжект** (`Resources/send.js`) — поиск чата, клик, ввод текста, отправка.
- **AppIntents** — Siri/Shortcuts интеграция + Control Center виджет.
- **BGTaskScheduler** — догонялка для пропущенных прогонов.
- **UNUserNotificationCenter** — ежедневные напоминания + snooze.

## Сборка из исходников

```bash
# Требуется: macOS с Xcode 16+, xcodegen
brew install xcodegen
xcodegen generate
xcodebuild -project Ugolek.xcodeproj -scheme Ugolek \
  -destination 'generic/platform=iOS Simulator' \
  -configuration Debug build
```

CI (GitHub Actions) собирает автоматически при каждом пуше в main.

## FAQ

**Безопасно ли для аккаунта?**
Уголёк имитирует действия пользователя в браузере — не использует API TikTok, не отправляет спам. Дрожание времени и случайные фразы снижают риск обнаружения. Но использование любой автоматизации — на ваш риск.

**Почему десктопный TikTok?**
Мобильная веб-версия TikTok устроена иначе: чат открывается отдельным «экраном», DOM-селекторы другие. Десктопная вёрстка (1920×1080) надёжнее для автоматизации — список и чат видны одновременно.

**Почему огонёк отмечается вручную?**
Веб-версия TikTok не отображает огоньки (стрики) вообще. Поэтому флажок «Есть огонёк 🔥» у каждого друга — ручной. Погасший огонёк восстановим (TikTok имеет Restore), поэтому флажок стоит держать включённым.

**Работает ли в фоне?**
Полный фон на iOS недостижим: WebView JS замерзает ~15 с после ухода в фон. Наш максимум: Shortcuts-автоматизация на разблокированном телефоне + уведомления + snooze + BGTask-догонялка.
