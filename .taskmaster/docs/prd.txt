PRD: Уголёк (Ugolek) — iOS-приложение для продления «огоньков» (стриков) TikTok

ОБЗОР
Нативное iOS-приложение (Swift + SwiftUI, iOS 17+, только iPhone, ноль сторонних зависимостей), которое автоматически отправляет короткие сообщения друзьям в TikTok, чтобы их «огоньки» (стрики) не гасли. Стрик живёт, если другу уходит минимум одно личное сообщение в календарный день. Приложение логинится в TikTok через встроенный WebView (сессия = cookie sessionid, хранится в Keychain), а затем по расписанию открывает веб-инбокс tiktok.com/messages в скрытом WKWebView и собственным JS-скриптом находит чат каждого друга, вводит и отправляет сообщение с верификацией доставки.

КЛЮЧЕВЫЕ АРХИТЕКТУРНЫЕ РЕШЕНИЯ
- Проект генерируется XcodeGen из project.yml (.xcodeproj не коммитится).
- Сборка через GitHub Actions на macOS-раннере: (а) быстрая debug-проверка компиляции, (б) неподписанный IPA в artifacts, (в) zip симуляторной сборки в artifacts для теста UI в браузере через Appetize.io.
- Распространение: sideload через AltStore/SideStore с бесплатным Apple ID.
- Так как iOS запрещает фоновый WebView, запуск прогона: ежедневное локальное уведомление → тап → приложение открывается → авто-прогон 10–40 сек → уведомление с итогом. Дополнительно: Shortcuts-автоматизация через App Intent (openAppWhenRun), кнопка ручного запуска, BGTaskScheduler для «догоняющих» проверок.
- Случайные паузы 2–6 сек между друзьями; максимум 1 сообщение в день каждому другу.
- Clean-room: код оригинала (TiktokStreakSaver, MIT) не копируется; в README указано «inspired by TiktokStreakSaver».
