# Установка Уголька

Приложение распространяется как sideload — ставится двумя способами:
настоящий iPhone через **AltStore** (основной) и быстрая проверка интерфейса в
**браузере через Appetize.io**.

Оба способа начинаются одинаково — забрать свежие артефакты сборки:

1. Открой репозиторий: **https://github.com/Noli4ekc/ugolek**
2. Вкладка **Actions** → самый верхний успешный запуск (зелёная галочка)
3. Внизу страницы раздел **Artifacts** — там два файла:
   - `Ugolek-unsigned-ipa` — для установки на iPhone
   - `Ugolek-simulator` — для браузерного превью
4. Скачай нужный (нужно быть залогиненным в GitHub в браузере). Скачается zip —
   распакуй его.

## Вариант 1. iPhone через AltStore (основной)

### Шаг 1. AltServer на компьютере с Windows (один раз)

1. Скачай **AltServer for Windows** с [altstore.io](https://altstore.io).
2. Перед установкой на компьютере должны стоять **iTunes и iCloud «с сайта
   Apple», а не из Microsoft Store** — это требование AltServer. Если стоят
   магазинные версии, удали и постав с сайта Apple:
   - iTunes: https://www.apple.com/itunes/
   - iCloud: https://support.apple.com/ru-ru/105026 (или с apple.com/icloud → «Скачать для Windows»)
3. Установи AltServer и запусти его — появится иконка молнии в трее.

### Шаг 2. AltStore на iPhone (один раз)

1. Подключи iPhone к компьютеру **кабелем** и разблокируй его.
2. Правый клик по иконке AltServer в трее → **Install AltStore** → выбери свой iPhone.
3. Введи свой Apple ID и пароль (если Apple ID нет — создай бесплатный на
   appleid.apple.com). Данные уходят только Apple для создания подписи разработчика.
4. На iPhone: **Настройки → Основные → VPN и управление устройством** → выбери
   свой Apple ID → **Доверять**.

### Шаг 3. Установка Уголька

1. Перекинь распакованный `Ugolek-unsigned.ipa` на iPhone (через iCloud Drive,
   «Файлы», или прямо скачать zip с GitHub в Safari и распаковать).
2. Открой **AltStore** на телефоне → вкладка **«+»** (вверху справа) → выбери
   `Ugolek-unsigned.ipa` → **Install**.
3. Через полминуты Уголёк появится на рабочем столе. Первый запуск — готово! 🔥

### Про 7 дней (важно)

Бесплатная подпись Apple живёт **7 дней**. AltStore продлевает её автоматически,
если: компьютер с запущенным AltServer включён, телефон рядом в той же Wi-Fi
сети, и в приложении «Здоровье»/фоне AltStore разрешена фоновая активность.
Проще говоря — пару раз в неделю держи комп включённым, и всё продлевается само.
Если приложение вдруг перестало запускаться — открой AltStore, он обновит подпись.

## Вариант 2. Браузер через Appetize.io (быстрая проверка UI)

> Appetize.io убрал публичную загрузку без аккаунта — нужен бесплатный
> профиль (Free plan: ~30 минут стриминга в месяц, этого хватает с запасом).

1. Зарегистрируйся на **[appetize.io](https://appetize.io)** (Sign Up, бесплатно).
2. Скачай и распакуй артефакт `Ugolek-simulator` — внутри окажется
   `Ugolek-simulator.zip` (внутренний zip, его не распаковывай).
3. В личном кабинете: **Apps → Upload App** → перетащи `Ugolek-simulator.zip`.
4. Приложение появится в списке → кнопка **Start** → в браузере откроется
   iPhone-симулятор → нажми **Tap to Start** — запустится Уголёк.

Ограничения: это симулятор в облаке — сеть, логин TikTok, уведомления и фоновые
задачи там полноценно не проверяются. Для всего настоящего — вариант 1.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| AltServer не видит iPhone | Оригинальный кабель; iTunes с сайта Apple (не из Store); в AltServer → Options включи «Allow AltPlugin updates» и перезагрузи комп |
| «Unable to install» в AltStore | Проверь, что доверяешь Apple ID (шаг 2.4); удали старую версию приложения и поставь заново |
| Приложение не открывается | Скорее всего истекла 7-дневная подпись — включи комп с AltServer, открой AltStore на телефоне, подожди минуту |
| Артефакты не скачиваются | Артефакты доступны только залогиненным в GitHub — войди в аккаунт в браузере |
