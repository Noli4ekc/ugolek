## Что это за проект
iOS-приложение **«Уголёк» (Ugolek)** — автоматически продлевает «огоньки» (стрики) в TikTok: в назначенное время открывает веб-инбокс `tiktok.com/messages` в скрытом WKWebView и рассылает сообщения друзьям. Clean-room переписывание с нуля (не копия форка `D:\modtt` / TiktokStreakSaver, хотя идея оттуда; в README есть «inspired by»).

- **Локальный репозиторий:** `D:\Ugolek`. **GitHub:** `Noli4ekc/ugolek` (публичный).
- **Стек:** Swift/SwiftUI, iOS 17+, генерация проекта XcodeGen (`project.yml`), ноль сторонних зависимостей.
- **Сборка:** GitHub Actions (macOS-раннер, бесплатно): compile-check + артефакт `Ugolek-unsigned-ipa` + симуляторный zip + **rolling-release** (job сам прикрепляет свежий IPA к релизу `rolling` при каждом пуше в main).
- **Установка пользователю (Кирилл):** через **Sideloadly** на его Windows-ПК. Всё сложено в `D:\sideload-tools\` (там же установщики iTunes/Sideloadly и свежий `Ugolek-unsigned.ipa` — я обновляю его curl'ом из rolling-релиза после каждой сборки).
- **Планирование:** Task Master в `D:\Ugolek\.taskmaster\tasks\tasks.json` — 33 задачи; выполнены 1–23, 28, 33; остались 24–27, 29–32 (Этапы F и G).

## Проверенные факты о TikTok DOM (2026-08-22; залогиненное состояние; окно 1920×1080)
- Список чатов: `[data-e2e='dm-new-conversation-item']`; внутри `a[href*='/@']` (юз), `[data-e2e='dm-new-conversation-nickname']` (ник), у строки есть `data-conv-id`, `aria-selected` при клике.
- Список появляется **с задержкой** (может >3 с) — ждём до 15 с (`waitForChatList`).
- Поле ввода: Draft.js `contenteditable.notranslate.public-DraftEditor-content` внутри `[data-e2e='dm-new-input-editor']`. Запасной путь: textarea в `[data-e2e='message-input-area']`.
- Кнопка отправки: элемент с `data-e2e` содержащим `send` — оказалась **SVG** (нет `.click()`) → сделан `safeClick` через события мыши.
- Пузыри сообщений: `[data-e2e='dm-new-message-text']`.
- **Разлогин не редиректит на /login**: страница показывает `[data-e2e='top-login-button']` → после загрузки проверяем и инвалидируем сессию (`SessionStore.invalidate`).
- **Огонёк (стрик) в веб-версии НЕ отображается вообще** (проверено полным сканированием DOM) → ручной флажок `Friend.hasFlame` + настройка «Только тем, у кого есть огонёк». Погасший огонёк восстановим (TikTok официально имеет Restore) → флажок держим включённым.
- TikTok **катит разные сборки вёрстки на живую** (хэши CSS-классов меняются между сессиями) → поведение «плавает».
- Десктопная раскладка (1920×1080) обязательна: на «средних» ширинах (1280) клик по чату не открывает панель; на 390 (мобильная) — чат-«экран» мог сбежать.
