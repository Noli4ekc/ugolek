Уголёк 🔥

Автоматическое продление огоньков (стриков) в TikTok.

Установка через AltStore

1. Установи AltStore

2. Добавь источник:

altstore://source?url=https://noli4ekc.github.io/ugolek/altstore-source.json

Добавить в AltStore

Установка через Sideloadly

1. Скачай IPA: последний релиз

2. Установи через Sideloadly по USB

После установки

1. Открой Уголёк → «Войти» → логинься в TikTok

2. Добавь друзей (username без @)

3. Нажми «Продлить сейчас» 🔥

Неофициальное приложение. Используй на свой риск.
